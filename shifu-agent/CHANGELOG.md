# Changelog

## 0.2.1 (beta)

- Versão para **NeoForge 1.21.1**, com o mesmo código da versão Fabric.
- Primeira versão testada num servidor de verdade: carrega, cria a configuração e responde aos comandos.
- O aviso de "não configurado" virou informativo, com a etiqueta `NOT_CONFIGURED`
  (antes aparecia como alerta de falha de conexão, o que assustava sem motivo).
- Logs sem o nível repetido no console e no arquivo.

## 0.2.0 (beta)

- Primeira versão pública.
- Entrega as compras da loja Shifu executando comandos de console.
- Funciona com qualquer mod ou plugin que tenha comando.
- Reconexão automática, diário contra entrega duplicada e comandos `/shifu status`, `reconnect`, `sync` e `test`.
